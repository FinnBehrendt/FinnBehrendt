# Hi, I'm Finn

I build machine learning software, with a focus on medical imaging and reproducible experiments. My PhD research explored how diffusion models can help detect anomalies in brain MRI without anomaly labels during training.

[LinkedIn](https://www.linkedin.com/in/finntobe) · [Publications](https://scholar.google.com/citations?user=cTxtesYAAAAJ&hl=en)

## Selected projects

- **[ChatCV](https://github.com/FinnBehrendt/ChatCV)** — A RAG application for résumé Q&A and job-fit analysis. I use it to experiment with LLM applications, from retrieval and model configuration to deployment and evaluation.
- **[Mahalanobis Distance for Anomaly Detection](https://github.com/FinnBehrendt/Mahalanobis-Unsupervised-Anomaly-Detection)** — Research code exploring how Mahalanobis distance can improve unsupervised anomaly detection in brain MRI.
- **[Conditioned Diffusion Models for Brain MRI](https://github.com/FinnBehrendt/Conditioned-Diffusion-Models-UAD)** — Guided reconstruction with diffusion models for unsupervised anomaly detection.
- **[Patched Diffusion Models (pDDPM)](https://github.com/FinnBehrendt/patched-Diffusion-Models-UAD)** — A patch-based diffusion approach to unsupervised anomaly detection in brain MRI.
- **[Unsupervised Anomaly Detection in Brain MRI](https://github.com/FinnBehrendt/Unsupervised-Anomaly-Detection-in-Brain-MRI)** — A companion repository to our review, bringing together datasets, methods, and open implementations.

I also contribute to [MONAI](https://github.com/Project-MONAI/MONAI), an open-source framework for medical imaging AI.
